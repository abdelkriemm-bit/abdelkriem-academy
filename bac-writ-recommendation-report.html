تانية بكالوريا · Writing · Unit 8

Recommendation Report

إزاي تكتب تقرير رسمي لمدير المدرسة تقترح فيه نشاط واحد وتشرح فوايده بالدليل (150-180 كلمة).

البكالوريا المصرية · Egyptian Baccalaureate › تانية بكالوريا English

الدرس ده عن إيه؟

A recommendation report is a formal piece of writing that suggests an idea or an action and explains why it should be adopted.

الـ recommendation report يعني «تقرير توصية»: إنت بتكتب لحد مسؤول (زي مدير المدرسة) وبتقوله: «أنا بقترح حاجة معينة، ودي أسبابي، ودي الفايدة اللي هتيجي منها، فياريت تنفذها».

في الكتاب الدرس ده في Unit 8: Pathways to Progress، جزء 8.3 The Egyptian-Japanese Schools (EJS)، في صفحة Writing in Action (صفحة 84-85). القراءة اللي قبلها اسمها A Different Way to Learn وبتتكلم عن أنشطة الـ Tokkatsu زي Cleaning Time (Soji) والـ class meetings. والمطلوب في الكتاب تقرير من 150-180 كلمة لمدير المدرسة تقترح فيه نشاط Tokkatsu واحد يحسّن سلوك الطلبة أو الـ teamwork أو المسؤولية.

وكمان في Consolidation Review D فيه سؤال True/False عن الـ recommendation report نفسه، يعني لازم تفهم هو إيه مش بس تكتبه.

الفكرة ببساطة: «أنا بقترح… وده السبب»

Think of it like this: What do you recommend? How does it work? Why is it useful? What should the reader do now?

تخيل إنك رايح لمدير المدرسة بفكرة. مش هينفع تقوله «عايزين نعمل نشاط حلو» وخلاص. لازم تقوله:

  1. إيه اللي بتقترحه بالظبط؟ (نشاط واحد واضح)
  2. إزاي هيتنفذ؟ (مين هيعمل إيه، وإمتى)
  3. ليه هو مفيد؟ (أسباب + دليل أو مثال)
  4. المطلوب من المدير إيه دلوقتي؟ (يوافق ويبدأ ينفذ)

وخلي بالك: ده تقرير رسمي (formal)، مش رسالة لصاحبك. يعني من غير هزار، ومن غير كلام عامي، ومن غير اختصارات زي don't و it's.

مواصفات التقرير زي ما الكتاب بيقول (Key Characteristics)

The book lists five main features of a good recommendation report.

Main Featureيعني إيه؟تعمل إيه في كتابتك؟
Clear purposeهدف واضحقول من الأول إنت بتقترح إيه بالظبط (It is recommended that…).
Formal toneأسلوب رسمياستخدم لغة موضوعية (objective) وابعد عن التعبيرات العامية والاختصارات.
Reasons and evidenceأسباب ودليلاشرح ليه الاقتراح مفيد وادعمه بأمثلة (من نموذج مدارس EJS مثلًا).
Logical organisationترتيب منطقيقدّم أفكارك بترتيب واضح: مقدمة ← الاقتراح ← الفوايد ← الخاتمة.
Action-oriented conclusionخاتمة فيها طلب تنفيذاختم بإنك تشجّع القارئ يوافق وينفذ الاقتراح.

الهيكل اللي الكتاب بيقترحه (Suggested Structure)

Introduction → Recommendation → Benefits → Conclusion. Each part has its own job.

Sectionوظيفتهاعبارات مفيدة
Introductionقول هدف التقرير وقدّم النشاط اللي بتقترحه.The purpose of this report is to… / It is recommended that…
Recommendationاوصف النشاط واشرح بيشتغل إزاي.One effective practice would be… / Each class could…
Benefitsاشرح هيحسّن إزاي السلوك، الـ teamwork، المسؤولية أو التواصل، وهات أمثلة أو دليل.This activity could help students… / This would improve… / Furthermore,… / As a result,…
Conclusionلخّص الاقتراح وشجّع المدرسة تنفذه.In conclusion,… / The school should consider…
شكل التقرير
  • التقرير غالبًا بيبدأ بسطور صغيرة: To: (لمين) / From: (مين) / Subject: (الموضوع).
  • وكل جزء ليه عنوان صغير (heading): Introduction / Recommendation / Benefits / Conclusion. ده بيخلي التقرير منظم وسهل القراية.
  • الكتاب بيطلب 150-180 كلمة (عدّ الكلام كله).

عبارات مفيدة (Useful Language)

دي العبارات اللي الكتاب بيديهالك، ومعاها شوية زيادة من نفس النوع. احفظ 2-3 من كل مجموعة.

Stating the purpose (المقدمة)

  • The purpose of this report is to recommend…
  • This report suggests one activity that could…
  • It is recommended that the school (should) introduce…

Making recommendations (من الكتاب)

  • It is recommended that…
  • The school should consider…
  • One effective practice would be…
  • This activity could help students…

Describing how it works

  • Each class could be divided into…
  • Students would take turns to…
  • The activity would take place every…

Giving reasons (من الكتاب)

  • This would improve…
  • Furthermore,…
  • Consequently,…
  • As a result,…
  • In addition,…

Giving evidence

  • For example, in the Egyptian-Japanese Schools,…
  • According to the text,…
  • This is shown by…

Concluding (خاتمة فيها طلب)

  • In conclusion,…
  • To sum up, I strongly recommend…
  • The school should consider starting… next term.
  • It is recommended that the school introduce a weekly class meeting.بعد It is recommended that بنستخدم الفعل في المصدر (introduce مش introduces). وممكن تقول should introduce.
  • The school should consider starting Cleaning Time next term.consider + فعل بـ ing (starting). دي من عبارات الكتاب للاقتراح.
  • One effective practice would be to let students organise their own class meeting.would هنا بتخلي الاقتراح مؤدب ورسمي.
  • This activity could help students become more responsible.help + شخص + فعل في المصدر (become).
  • Students would clean their classrooms. Consequently, they would respect the school more.Consequently = ونتيجة لكده. بتربط السبب بالنتيجة.
  • Furthermore, the activity costs almost nothing.Furthermore = وكمان (بتضيف سبب جديد).

إزاي تكتب التقرير خطوة بخطوة

  1. اقرا السؤال كويس: لمين التقرير (principal)؟ عن إيه (نشاط Tokkatsu واحد)؟ وعايز يحسّن إيه (behaviour / teamwork / responsibility)؟
  2. اختار نشاط واحد بس من القراءة: Cleaning Time (Soji) أو class meetings أو group discussions. متقترحش 3 حاجات مرة واحدة.
  3. اكتب سطور To / From / Subject في أول التقرير.
  4. Introduction (جملتين): هدف التقرير + اسم النشاط اللي بتقترحه بعبارة زي It is recommended that…
  5. Recommendation (2-3 جمل): النشاط ده إيه؟ بيتعمل إزاي؟ مين بيعمل إيه؟ وإمتى؟
  6. Benefits (3-4 جمل): سببين أو تلاتة بالـ connectors (Furthermore / Consequently / As a result) + مثال أو دليل من نموذج EJS.
  7. Conclusion (جملتين): لخّص الاقتراح + اطلب من المدير ينفذه (The school should consider…).
  8. راجع: العدد 150-180 كلمة؟ مفيش اختصارات (don't / it's)؟ مفيش كلام عامي؟
حيلة: سؤال لكل جزء
  • Introduction ← إيه اللي بقترحه؟
  • Recommendation ← بيتعمل إزاي؟
  • Benefits ← ليه مفيد؟ وإيه الدليل؟
  • Conclusion ← المطلوب إيه دلوقتي؟

نموذج كامل (Model Answer)

Recommendation Report: Cleaning Time (Soji)177 words · يغطي كل نقاط «Your Report Should Include» في الكتاب
Task: Write a recommendation report of (150-180) words for your school principal suggesting one Tokkatsu activity that could improve student behaviour, teamwork or responsibility.

To: The School Principal

From: Omar Hassan, Class 2B

Subject: Introducing Cleaning Time (Soji)

Introduction

The purpose of this report is to recommend one Tokkatsu activity that could improve student behaviour and responsibility. It is recommended that our school introduce Cleaning Time, known in Japan as Soji.

Recommendation

Soji is a short activity in which students work together to clean their classrooms and shared spaces. Each class could be divided into small groups, and every group would be responsible for one area, such as the desks or the corridor. Groups would change tasks weekly.

Benefits

This activity could help students become more responsible because they would take care of their own environment instead of relying on others. Furthermore, it would improve teamwork, since each group must cooperate. As a result, students would also show more appreciation for all forms of work. For example, Soji is one of the best-known Tokkatsu activities in the Egyptian-Japanese Schools, where it teaches these values.

Conclusion

In conclusion, Cleaning Time is simple and effective. The school should consider starting it next term.

ليه النموذج ده قوي؟
  • To / From / Subject: شكل التقرير الرسمي. الـ Subject بيقول الموضوع في كلمتين.
  • Introduction: فيها الـ clear purpose (The purpose of this report is to…) واسم النشاط بعبارة الكتاب It is recommended that… والفعل introduce في المصدر.
  • Recommendation: بتوصف النشاط وبيشتغل إزاي (groups – areas – change tasks every week). مفيش أسباب هنا، الأسباب في الجزء اللي بعده.
  • Benefits: 3 فوايد مربوطة بـ connectors من الكتاب: because / Furthermore / As a result. وكل فايدة من اللي السؤال طالبها: responsibility و teamwork.
  • Evidence: جملة For example, … in the Egyptian-Japanese Schools هي الدليل من القراءة (السؤال بيطلب Evidence or examples from the EJS model).
  • Formal tone: مفيش ولا اختصار (don't / it's) ولا كلمة عامية. الجمل موضوعية.
  • Action-oriented conclusion: آخر جملة بتطلب من المدير يعمل حاجة: The school should consider starting it next term.
  • Relative clauses ( in which students… / where it teaches…) بتخلي الكتابة أدق، ودي من قواعد الكتاب في Unit 1.

أشهر الأخطاء

غلط ← صح
  • ✗ I think it's a good idea to clean. ← ✓ It is recommended that the school introduce Cleaning Time. (رسمي ومن غير اختصار)
  • ✗ تقترح 3 أنشطة في نفس التقرير ← ✓ نشاط واحد زي ما السؤال طالب (one Tokkatsu activity).
  • ✗ It is recommended that the school introduces… ← ✓ … that the school introduce / should introduce…
  • ✗ The school should consider to start… ← ✓ The school should consider starting…
  • ✗ This activity could help students to became… ← ✓ … help students become…
  • ✗ تكتب فوايد من غير دليل ← ✓ ضيف مثال من نموذج EJS (For example, in the Egyptian-Japanese Schools,…).
  • ✗ تختم بـ That's all. ← ✓ اختم بطلب: The school should consider starting it next term.
  • ✗ تكتب 90 كلمة أو 250 كلمة ← ✓ الالتزام بـ 150-180 كلمة.

إزاي بييجي في الأسئلة؟

الأسئلة في الكتاب والمراجعات بتيجي بالشكل ده:

1) True / False + Justification (زي Consolidation Review D):

A recommendation report only describes a problem and does not suggest any action.

الإجابة: False. Justification: A recommendation report suggests an idea or action and explains why it should be adopted. — التقرير لازم يقترح حاجة ويشرح ليه نتبناها، مش بس يوصف مشكلة.

2) اختار الجملة الأنسب للخاتمة (MCQ):

Which sentence is the best action-oriented conclusion? a) Soji is a Japanese word. b) I hope you enjoyed my report. c) The school should consider starting Soji next term. d) Many students like football.

الإجابة: c — لأنها بتطلب من القارئ ينفذ الاقتراح، وده معنى action-oriented conclusion.

3) حوّل الجملة لأسلوب رسمي:

We gotta have class meetings, they're super cool!

الإجابة: It is recommended that the school hold weekly class meetings, as they would improve communication. — شلنا gotta و they're و super cool وحطينا عبارة توصية رسمية + سبب.

قائمة المراجعة (Checklist)

  • كتبت To / From / Subject؟
  • اقترحت نشاط واحد واضح في الـ Introduction؟
  • شرحت النشاط بيشتغل إزاي؟
  • كتبت سببين على الأقل بـ connectors (Furthermore / Consequently / As a result / In addition)؟
  • ضفت مثال أو دليل من نموذج EJS؟
  • الأسلوب رسمي: مفيش اختصارات ولا كلام عامي؟
  • الخاتمة فيها طلب تنفيذ؟
  • العدد بين 150 و180 كلمة؟ راجعت الـ spelling والـ punctuation؟

تدريب

أولًا: اختار الإجابة الصحيحة (a / b / c / d)

  1. 1. A recommendation report is mainly written to … a) tell a funny story b) suggest an action and explain why it should be adopted c) describe a holiday d) give a list of rules

    Show answer
    b — ده تعريف الكتاب: suggests an idea or action and explains why it should be adopted.

  2. 2. Which phrase is used for making a recommendation? a) Once upon a time b) Dear friend c) It is recommended that d) See you soon

    Show answer
    c — It is recommended that من عبارات الكتاب للاقتراح.

  3. 3. The tone of a recommendation report should be … a) informal b) formal and objective c) emotional d) humorous

    Show answer
    b — Formal tone: objective language، من غير تعبيرات عامية.

  4. 4. The school should consider … a weekly class meeting. a) start b) to start c) starting d) started

    Show answer
    c — consider + فعل بـ ing.

  5. 5. Students would work in groups. … , they would learn to cooperate. a) Consequently b) Although c) Unless d) However

    Show answer
    a — Consequently = ونتيجة لكده (نتيجة)، مش تناقض زي However.

  6. 6. In which section do you describe how the activity works? a) Introduction b) Recommendation c) Benefits d) Conclusion

    Show answer
    b — الـ Recommendation: Describe the activity + Explain how it works.

  7. 7. It is recommended that every class … its own meeting once a week. a) holds b) held c) hold d) holding

    Show answer
    c — بعد It is recommended that بنستخدم الفعل في المصدر (hold).

ثانيًا: True (T) أو False (F) مع التبرير (Justify)

  1. 8. A good recommendation report can include several unrelated ideas in any order.

    Show answer
    False — لازم logical organisation: Present your ideas in a clear order.

  2. 9. The conclusion should encourage the reader to adopt the recommendation.

    Show answer
    True — ده الـ action-oriented conclusion.

  3. 10. Contractions such as 'don't' and 'it's' are suitable in a recommendation report.

    Show answer
    False — التقرير formal، فبنكتب do not و it is.

  4. 11. Reasons in the report should be supported with examples or evidence.

    Show answer
    True — Reasons and evidence: Explain why… and support it with examples.

ثالثًا: رتّب أجزاء التقرير / حط العبارة في مكانها

  1. 12. In which section does this sentence belong? 'The purpose of this report is to recommend class meetings.'

    Show answer
    Introduction — بتقول هدف التقرير.

  2. 13. In which section does this sentence belong? 'Furthermore, class meetings would improve communication between students.'

    Show answer
    Benefits — سبب/فايدة مربوطة بـ Furthermore.

  3. 14. In which section does this sentence belong? 'The school should consider starting class meetings next month.'

    Show answer
    Conclusion — طلب تنفيذ.

  4. 15. In which section does this sentence belong? 'Every Thursday, students would sit in a circle and choose one problem to discuss.'

    Show answer
    Recommendation — بتشرح النشاط بيشتغل إزاي.

  5. 16. Put the sections in the correct order: Benefits / Conclusion / Introduction / Recommendation

    Show answer
    Introduction → Recommendation → Benefits → Conclusion — زي الـ Suggested Structure في الكتاب.

رابعًا: صحّح أو حوّل لأسلوب رسمي

  1. 17. Rewrite formally: 'Cleaning is a really cool idea, guys!'

    Show answer
    مثال: Cleaning Time would be a useful activity for our school. — شلنا really cool و guys.

  2. 18. Correct the mistake: 'This activity could help students to became more responsible.'

    Show answer
    This activity could help students become more responsible. — help + شخص + المصدر.

  3. 19. Join with a suitable connector: 'Students would clean the school themselves. They would respect it more.'

    Show answer
    Students would clean the school themselves. As a result, they would respect it more.

  4. 20. Write ONE sentence giving evidence from the EJS model.

    Show answer
    مثال: For example, in the Egyptian-Japanese Schools, students take part in group discussions and class meetings where they solve problems together. — دليل من القراءة.

خامسًا: JRE

  1. 21. Why is Cleaning Time (Soji) a good activity to recommend to a school principal? (Justify – Reasoning – Evidence)

    Show answer
    J: Soji is a good activity to recommend because it builds responsibility. R: Students learn to care for their own school instead of relying on others, and they learn to work as a team. E: For example, the text explains that Soji teaches responsibility, respect for the environment and appreciation for all forms of work.

ملخص الدرس في سطرين
  • الـ recommendation report = تقرير رسمي بيقترح حاجة واحدة ويشرح ليه نتبناها.
  • الهيكل: Introduction ← Recommendation ← Benefits ← Conclusion + سطور To / From / Subject.
  • عبارات أساسية: It is recommended that… / The school should consider… / One effective practice would be… / This would improve…
  • الفوايد لازم يكون معاها أسباب + connectors + دليل (من نموذج EJS).
  • الخاتمة بتطلب تنفيذ، والطول 150-180 كلمة.
