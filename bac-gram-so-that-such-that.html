تانية بكالوريا · Grammar · Unit 9

So… that / Such… that

إزاي نقول «لدرجة إن» في الإنجليزي: so + صفة + that، و such + (a) + صفة + اسم + that.

البكالوريا المصرية · Egyptian Baccalaureate › تانية بكالوريا English

الدرس ده عن إيه؟

We use so … that and such … that to show the result of a very strong quality, quantity or feeling: The idea was so simple that everyone understood it.

في العربي بنقول: «الفكرة كانت بسيطة لدرجة إن كل الناس فهموها». الجملة فيها حاجتين: صفة قوية (بسيطة جدًا) ونتيجة حصلت بسببها (كل الناس فهموها).

في الإنجليزي بنعبّر عن «لدرجة إن» بطريقتين: so … that وsuch … that. المعنى واحد، الفرق بس في الكلمة اللي جاية بعد so أو such.

في الكتاب الدرس ده موجود في Unit 9: Circles of Belonging، درس 9.3 No One Left Behind (Section B: Inclusion and Community Action)، جزء Grammar Focus: so…that / such…that (صفحة 117)، وبييجي تاني في Consolidation Review E. الأمثلة هناك عن مبادرة الـ Buddy Bench وإزاي فكرة صغيرة عملت أثر كبير.

الفكرة ببساطة: سبب قوي ← نتيجة

The first part shows the degree (how strong). The that-clause shows the result.

كل جملة من دول ليها جزئين:

الجزء الأول: الدرجة (قد إيه؟)thatالجزء التاني: النتيجة (حصل إيه؟)
The bench was so popularthata second one was added.
It was such a kind gesturethatthe boy smiled all day.

يعني بنقول الصفة، ونعليها بـ so أو such علشان نقول «جدًا لدرجة»، وبعدين نقول النتيجة بعد that.

  • The bench was popular. A second one was added.جملتين منفصلين: سبب + نتيجة.
  • The bench was so popular that a second one was added.جملة واحدة: الدكة كانت مشهورة لدرجة إن اتضافت دكة تانية.

القاعدة الذهبية: بص على اللي بعدها

Use so before an adjective or adverb alone (or many / much / few / little). Use such before a noun (with or without an adjective).

القاعدة كلها في سؤال واحد: فيه اسم (noun) بعد الصفة ولا لأ؟

  • لو مفيش اسم (صفة لوحدها أو ظرف) ← so: so simple / so quickly.
  • لو فيه اسم ← such: such a simple idea / such caring volunteers.
  • لو الاسم بييجي بعد many / much / few / little ← so: so many students / so much support.
التركيبةإمتى؟مثال
so + adjective + thatصفة لوحدهاThe idea was so simple that everyone understood it.
so + adverb + thatظرف (بيوصف الفعل)She spoke so confidently that the class listened.
so many + countable noun + thatعدد كبير (حاجات بتتعد)So many students joined that a second bench was added.
so much + uncountable noun + thatكمية كبيرة (حاجات مبتتعدش)There was so much noise that I couldn't hear him.
so few / so little + noun + thatعدد / كمية صغيرة جدًاSo few people came that the event was cancelled.
such a / an + adjective + singular noun + thatاسم مفرد بيتعدIt was such a small idea that few people expected it to work.
such + adjective + plural noun + thatاسم جمع (من غير a)They were such caring volunteers that the whole school noticed.
such + adjective + uncountable noun + thatاسم مبيتعدش (من غير a)She gave such good advice that I followed it.
حيلة للحفظ
  • such فيها ch زي chair = اسم. يعني such ← اسم.
  • so ← sifa (صفة) لوحدها.
  • a / an بتيجي بعد such: such a … ✓ — مش a such ✗، ومش so a ✗.
  • many / much / few / little دايمًا مع so حتى لو بعدهم اسم.

مكان a / an: أكتر غلطة في الامتحان

Say such a simple idea. Do not say *a so simple idea*, *so a simple idea* or *such simple idea*.

Review E بتجيب سؤال بالشكل ده. بص على الأربع اختيارات دي واعرف ليه 3 منهم غلط:

  • ✗ It was a so clever plan that the whole class joined in.غلط: so مش بتيجي قبل اسم، وa مش مكانها.
  • ✗ It was so a clever plan that the whole class joined in.غلط: so قبل a مش مستخدمة في الإنجليزي العادي.
  • ✗ It was such clever plan that the whole class joined in.غلط: plan مفرد بيتعد فلازم a.
  • ✓ It was such a clever plan that the whole class joined in.صح: such + a + صفة + اسم مفرد.

ولو الاسم جمع أو مبيتعدش يبقى من غير a: such kind people / such useful information / such bad weather.

أسماء مبتتعدش (uncountable) خلي بالك منها

advice / information / support / news / weather / help / progress / furniture / homework — كلهم من غير a: such good advice ✓ — such a good advice ✗. ولو عايز تستخدم so: so much advice / so much support.

التحويل بين so و such (Rewrite)

You can often say the same idea with so or such: The volunteers were so caring that… = They were such caring volunteers that…

سؤال مشهور: «أعد كتابة الجملة باستخدام such بدل so» أو العكس. الطريقة:

منإلىالخطوات
The idea was so simple that…It was such a simple idea that…حط It was + such + a + الصفة + الاسم.
The volunteers were so caring that…They were such caring volunteers that…جمع ← They were + such + الصفة + الاسم (من غير a).
It was such a powerful message that…The message was so powerful that…الاسم يبقى الفاعل + was + so + الصفة.
It was such good advice that…The advice was so good that…uncountable ← The advice was so good.

لاحظ إن الضمير بيتغير حسب الاسم: مفرد ← It was / He was / She was. جمع ← They were.

so that ≠ so … that

so that (together) shows purpose: I sat on the bench so that someone would talk to me. so + adjective + that shows result.

فيه تركيبة شبهها جدًا بس معناها مختلف:

  • He sat on the bench so that someone would talk to him.so that لازقين = علشان / بهدف إن (purpose). هنا هو قعد علشان حد يكلمه.
  • He was so lonely that he sat on the bench.so + صفة + that = لدرجة إن (result). كان وحيد لدرجة إنه قعد على الدكة.

الفرق ببساطة: لو فيه صفة بين so و that ← لدرجة إن (نتيجة). لو so that لازقين ← علشان (هدف).

so / such ولا too / enough؟

too + adjective + to shows a negative result (something is not possible). adjective + enough + to shows something is possible. so / such … that can show any result.

  • The boy was too shy to ask the others to play.too = زيادة عن اللزوم ← ما قدرش يسأل (نتيجة سلبية).
  • The boy was so shy that he didn't ask the others to play.نفس المعنى بـ so … that (لاحظ إننا كتبنا جملة كاملة بعد that).
  • The bench was big enough for three children.enough = كفاية. بييجي بعد الصفة.

في Review E كان من ضمن الاختيارات too وenough جنب so و such. خلي بالك: الجملة لو آخرها that + جملة كاملة ← so أو such، مش too ولا enough.

أمثلة من موضوعات الوحدة

الأمثلة دي كلها من جو Unit 9: الانتماء، الإحساس بالوحدة في المدرسة، الـ Buddy Bench، والمبادرات الصغيرة اللي بتفرق.

  • The playground was so crowded that nobody noticed the new boy.الملعب كان زحمة لدرجة إن محدش لاحظ الولد الجديد.
  • Exclusion is such a quiet problem that teachers often miss it.الاستبعاد مشكلة هادية لدرجة إن المدرسين كتير مبياخدوش بالهم منها.
  • So many children used the bench that the school bought another one.عيال كتير قوي استخدموا الدكة لدرجة إن المدرسة اشترت واحدة تانية.
  • She felt so welcome after joining the club that she never missed a meeting.حست إنها مرحب بيها لدرجة إنها ما فوّتتش ولا اجتماع.
  • They were such friendly classmates that I soon felt at home.كانوا زمايل لطاف جدًا لدرجة إني بسرعة حسيت إني في بيتي.
  • The mentor gave me such useful feedback that my next essay was much better.المرشد ادّاني ملاحظات مفيدة لدرجة إن المقال اللي بعده كان أحسن بكتير. (feedback مبتتعدش ← من غير a)
  • There was so little support for new students that many felt lost.الدعم للطلبة الجداد كان قليل جدًا لدرجة إن كتير منهم حسوا إنهم تايهين.
  • He spoke so honestly about his loneliness that the whole class listened.اتكلم بصراحة عن وحدته لدرجة إن الفصل كله سمعه. (honestly ظرف ← so)
  • It was such an inspiring talk that ten students volunteered the next day.كانت محاضرة ملهمة لدرجة إن 10 طلبة اتطوعوا تاني يوم. (an قبل inspiring لأنها بتبدأ بصوت متحرك)
  • The online campaign spread so quickly that the whole neighbourhood joined in.الحملة على النت انتشرت بسرعة لدرجة إن الحي كله شارك.

إزاي نستخدمها في الكتابة والـ JRE

In a personal narrative or a discursive essay, so / such … that makes your evidence stronger because it links a cause to a clear result.

الدرس ده بييجي جنب كتابة الـ personal narrative والـ discursive essay في الوحدة. so / such … that بتخلي كلامك أقوى لأنها بتربط السبب بـالنتيجة في جملة واحدة. شوف الفقرة دي:

Justify: Small inclusion projects can change a school. Reason: Loneliness is such a hidden problem that it often goes unnoticed. Evidence: For example, after our school introduced a Buddy Bench, so many students started playing together that the teachers reported fewer children sitting alone.

لاحظ: الجملة الأولى فيها such + a + صفة + اسم، والتانية فيها so many + اسم جمع. والنتيجة بعد that في الحالتين جملة كاملة (فاعل + فعل).

أشهر الأخطاء (غلط ← صح)
  • ✗ It was so a kind gesture that… ← ✓ It was such a kind gesture that…
  • ✗ It was a such kind gesture that… ← ✓ It was such a kind gesture that… (a بعد such)
  • ✗ They were such kind that… ← ✓ They were so kind that… (مفيش اسم بعد الصفة ← so)
  • ✗ She gave me such a good advice that… ← ✓ She gave me such good advice that… (advice مبتتعدش)
  • ✗ Such many students came that… ← ✓ So many students came that…
  • ✗ The idea was very simple that everyone understood. ← ✓ The idea was so simple that… (very مبتيجيش مع that)
  • ✗ The idea was so simple so everyone understood it. ← ✓ The idea was so simple that everyone understood it. (النتيجة بتبدأ بـ that)
إزاي تجاوب بسرعة في الامتحان
  • بص على الكلمة بعد الفراغ: a / an ← such. صفة وبعدها اسم ← such. صفة لوحدها أو ظرف ← so. many / much / few / little ← so.
  • لو الاختيارات فيها too وenough: لو آخر الجملة that + جملة كاملة ← so أو such.
  • في سؤال «Complete with the appropriate structure ( such )»: متكتبش اللي بين القوسين وخلاص. لو بعده صفة لوحدها حوّلها لـ so. (زي Review E: The project was ___ (such) welcoming ← so)
  • في الدمج: السبب الأول + so / such، والنتيجة بعد that، وشيل كلمات زي «So» أو «As a result» من الجملة التانية.

إزاي بييجي في الأسئلة؟

الأسئلة في الكتاب والمراجعات بتيجي بالأشكال دي. هنحل مثال لكل شكل:

1) Choose the correct answer.

The talk was ______ moving that several students cried.

a. such b. so c. too d. enough

الإجابة: b. so. ليه؟ بعد الفراغ صفة لوحدها (moving) ومفيش اسم، وآخر الجملة that + جملة ← so. (too / enough مبيجوش مع that بالشكل ده)

2) Only one sentence in each group is grammatically correct.

a. They were such a helpful mentors that we all improved.

b. They were so helpful mentors that we all improved.

c. They were such helpful mentors that we all improved.

d. They were such helpful that we all improved.

الإجابة: c. mentors جمع ← such + صفة + اسم جمع من غير a. (a) a مع جمع غلط. (b) so قبل اسم غلط. (d) such من غير اسم غلط.

3) Combine the two sentences using so…that or such…that.

The programme is successful. Other governorates want to copy it.

الإجابة: The programme is so successful that other governorates want to copy it. أو: It is such a successful programme that other governorates want to copy it. الاتنين صح، واحدة بـ so (صفة لوحدها) والتانية بـ such (صفة + اسم).

تدريب

A. Complete the sentences with so or such.

  1. 1. The new student was ______ quiet that nobody knew his name.

    Show answer
    so — صفة لوحدها (quiet).

  2. 2. It was ______ a warm welcome that I forgot my fears.

    Show answer
    such — بعد الفراغ a.

  3. 3. ______ many parents came to the meeting that some of them had to stand.

    Show answer
    So — many دايمًا مع so.

  4. 4. They are ______ kind neighbours that they check on my grandmother every day.

    Show answer
    such — صفة + اسم جمع (neighbours).

  5. 5. The workshop gave us ______ useful information that we used it at once.

    Show answer
    such — information اسم مبيتعدش ومفيش a.

  6. 6. He apologised ______ sincerely that his friend forgave him immediately.

    Show answer
    so — sincerely ظرف.

  7. 7. There was ______ little time that we couldn't finish the poster.

    Show answer
    so — little دايمًا مع so.

B. Choose the correct answer from a, b, c or d.

  1. 8. The Buddy Bench was ______ simple idea that many schools copied it. a. so b. such a c. a such d. so a

    Show answer
    b. such a — idea مفرد بيتعد: such + a + صفة + اسم.

  2. 9. The playground was so noisy ______ I couldn't hear my friend. a. than b. as c. that d. so

    Show answer
    c. that — so … that = لدرجة إن.

  3. 10. Her story was ______ that the whole school talked about it. a. such inspiring b. so inspiring c. such an inspiring d. too inspiring

    Show answer
    b. so inspiring — صفة لوحدها ومفيش اسم بعدها.

  4. 11. We had ______ bad weather that the charity run was postponed. a. such a b. so c. such d. so much

    Show answer
    c. such — weather مبتتعدش ← such + صفة + اسم من غير a.

  5. 12. Mona joined the art club ______ she could meet new friends. a. so that b. such that c. so … that d. too

    Show answer
    a. so that — هنا الهدف (علشان تقابل أصحاب جداد) مش نتيجة.

  6. 13. ______ few students attended the meeting that it was cancelled. a. Such b. Such a c. So d. Too

    Show answer
    c. So — few دايمًا مع so.

C. Combine each pair of sentences using so…that or such…that.

  1. 14. The campaign was powerful. Even adults started using its message at work.

    Show answer
    The campaign was so powerful that even adults started using its message at work. — أو: It was such a powerful campaign that …

  2. 15. Karim is a generous mentor. He spends his free time helping younger students.

    Show answer
    Karim is such a generous mentor that he spends his free time helping younger students. — صفة + اسم مفرد ← such a.

  3. 16. Many people offered help. The organisers had to refuse some of it.

    Show answer
    So many people offered help that the organisers had to refuse some of it.

  4. 17. The volunteers were patient. The shy children slowly began to join in.

    Show answer
    The volunteers were so patient that the shy children slowly began to join in. — أو: They were such patient volunteers that …

D. Rewrite each sentence as shown. Then find and correct the mistakes.

  1. 18. Rewrite using such: The idea was so effective that other schools adopted it.

    Show answer
    It was such an effective idea that other schools adopted it. — an لأن effective بتبدأ بصوت متحرك.

  2. 19. Rewrite using so: They were such supportive friends that I never felt alone.

    Show answer
    My friends were so supportive that I never felt alone. — شلنا الاسم بعد الصفة فبقت so.

  3. 20. Find and correct the mistake: It was so a long queue that we waited for an hour.

    Show answer
    It was such a long queue that we waited for an hour. — قبل a لازم such.

  4. 21. Find and correct the mistake: She gave me such a good advice that I followed it.

    Show answer
    She gave me such good advice that I followed it. — advice مبتتعدش فمفيش a.

  5. 22. Complete with the appropriate structure: The new club was (such) ______ friendly that I joined it on the first day.

    Show answer
    so friendly — بعده صفة لوحدها، فلازم نحوّل such لـ so. (ده نفس شكل أسئلة Review E)

  6. 23. Write ONE sentence about a small act of inclusion you have seen. Use such…that.

    Show answer
    مثال: It was such a small act of kindness that I nearly missed it, but it made the new girl smile for the rest of the day.

  • so + صفة لوحدها أو ظرف، وso many / much / few / little + اسم.
  • such + (a / an) + صفة + اسم. مع الجمع والـ uncountable من غير a.
  • الترتيب: such a ✓ — مش a such ولا so a.
  • so that لازقين = علشان (هدف)، مش لدرجة إن.
