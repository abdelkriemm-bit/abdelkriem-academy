تانية بكالوريا · Writing · Unit 10

Problem-Solution Paragraph

إزاي تكتب فقرة واحدة تسمّي فيها مشكلة مخفية في الشراء أونلاين وتقترح ليها حل واقعي وتبرره (حوالي 150-180 كلمة).

تانية بكالوريا English

الدرس ده عن إيه؟

A problem-solution paragraph clearly names an issue, explains why it matters, and then proposes a specific, realistic solution. It is shorter and more focused than a full proposal or essay.

الـ problem-solution paragraph يعني «فقرة مشكلة وحل». إنت بتكتب فقرة واحدة بتقول فيها: فيه مشكلة معينة، ودي أسبابها وليه هي مهمة، وده حل واحد واقعي ليها، وده ليه الحل ده هينفع.

في الكتاب الدرس ده في Unit 10: Behind the Buy، جزء 10.1 Hidden Cost of a Click، صفحة Writing in Action (صفحة 134-135). القراءة بتتكلم عن التكاليف المخفية (hidden costs) للشراء أونلاين: عربيات التوصيل اللي ماشية نص فاضية، العلب الكبيرة على حاجة صغيرة، والهدوم المرتجعة اللي بتترمي. والمطلوب فقرة حوالي 150-180 كلمة لمجلة المدرسة (school newsletter) عن تكلفة مخفية واحدة للشراء أونلاين أو ثقافة التوصيل.

وفي Consolidation Review E فيه سؤال MCQ: الـ problem-solution paragraph لازم تقول المشكلة بوضوح وتقترح حل واقعي وتبرره.

الفكرة ببساطة: «دكتور بيشخّص ويكتب علاج»

Think of a doctor: first he names the illness, then he explains the cause, then he gives one clear treatment and tells you why it works.

الدكتور مبيقولكش «إنت تعبان» وخلاص. بيقولك: «عندك إيه بالظبط (المشكلة)، ليه حصل (السبب)، خد العلاج ده (الحل)، وهيفيدك علشان كذا (التبرير)». الفقرة دي نفس الفكرة بالظبط.

خلي بالك من حاجتين مهمين:

  • مشكلة واحدة بس (ONE specific problem): مش «الشراء أونلاين وحش». لأ: «عربيات التوصيل اللي ماشية نص فاضية» مثلًا.
  • حل واحد بس وواقعي (ONE realistic, specific solution): مش «نبطّل نشتري أونلاين خالص». لأ: حاجة ممكن تتنفذ فعلًا، زي «يوم توصيل واحد في الأسبوع».

والفرق بينها وبين الـ recommendation report في Unit 8: التقرير فيه عناوين وأجزاء ورايح لشخص مسؤول، لكن الـ problem-solution paragraph فقرة واحدة مركزة من غير عناوين.

الهيكل زي ما الكتاب بيعلّمه

The book divides the paragraph into five parts. Each part has its own purpose and useful phrases.

Sectionوظيفتها (Purpose)عبارات مفيدة (Useful Phrases)
Problemقول المشكلة بوضوح في أول جملة (topic sentence).A major problem with… is… / Currently, …
Explanationاشرح ليه المشكلة بتحصل وليه هي مهمة (النتيجة على البيئة أو الناس).This happens because… / As a result, …
Proposed Solutionاقترح حل واحد محدد وواقعي واشرح بيتنفذ إزاي.One possible solution would be to… / A practical way to address this is…
Justificationاشرح ليه الحل ده هينفع.This would help by… / This is effective because…
Conclusionجملة ختام بتربط الحل بالنتيجة الكويسة.Overall, … / If this solution were adopted, …
فقرة واحدة = 5 أجزاء جوه بعض

كل الأجزاء دي بتتكتب ورا بعض في فقرة واحدة من غير عناوين. تقريبًا: جملة للمشكلة، 2-3 جمل للشرح، 2 للحل، 2-3 للتبرير، وجملة للخاتمة.

عبارات مفيدة (Useful Phrases)

Problem (من الكتاب)

  • A major problem with… is…
  • Currently, …
  • One hidden cost of… is…

Explanation (من الكتاب)

  • This happens because…
  • As a result, …
  • This matters because…
  • Consequently, …

Proposed solution (من الكتاب)

  • One possible solution would be to…
  • A practical way to address this is…
  • Online stores could…
  • Schools / Families could…

Justification (من الكتاب)

  • This would help by…
  • This is effective because…
  • In this way, …

Conclusion (من الكتاب)

  • Overall, …
  • If this solution were adopted, … would…
  • A major problem with online shopping is the huge amount of packaging waste.جملة المشكلة: واضحة ومحددة (packaging waste).
  • Currently, many customers return clothes after wearing them only once.Currently = حاليًا، بتوصف الوضع دلوقتي.
  • This happens because returns are free and painless for the customer.بتشرح السبب.
  • As a result, a large number of returned items end up in landfill.بتشرح النتيجة وليه المشكلة مهمة. (landfill = مقلب زبالة)
  • One possible solution would be to charge a small fee for returns.الحل بـ would = اقتراح مؤدب.
  • This would help by encouraging shoppers to think before they buy.help by + فعل بـ ing.
  • This is effective because it does not stop people from shopping online.التبرير: ليه الحل واقعي وهينفع.
  • If this solution were adopted, fewer clothes would be destroyed.Second conditional: If + past (were) ← would + المصدر. بنستخدمها للنتيجة المتوقعة.

قواعد الوحدة اللي تخدم الفقرة: Quantifiers

Unit 10 teaches quantifiers. They help you describe how big a problem is: too much / too many, a large amount of, a large number of, few / little.

Quantifierمع إيه؟معناهمثال
too muchاسم مبيتعدّش (uncountable)كتير زيادة عن اللزومtoo much packaging
too manyاسم بيتعدّ جمع (countable)كتير زيادة عن اللزومtoo many vans
a large amount ofuncountableكمية كبيرة منa large amount of waste / water
a large number ofcountable جمععدد كبير منa large number of parcels
few / a fewcountable جمعقليل جدًا (سلبي) / شوية (إيجابي)few customers know / a few items
little / a littleuncountableقليل جدًا (سلبي) / شوية (إيجابي)little information / a little effort
حيلة: much و amount مع اللي مبيتعدّش
  • لو تقدر تقول two / three قبل الاسم (two vans، three parcels) ← استخدم many / a large number of / few.
  • لو مينفعش تعدّه (waste, packaging, water, information) ← استخدم much / a large amount of / little.

إزاي تكتب الفقرة خطوة بخطوة

  1. اختار تكلفة مخفية واحدة من الدرس: half-empty delivery vans / oversized packaging / returned clothes that are destroyed / warehouse workers walking many kilometres.
  2. اكتب جملة المشكلة (A major problem with… is…). لازم تبقى محددة.
  3. اشرح السبب والنتيجة (This happens because… / As a result,…) واستخدم quantifier يبيّن حجم المشكلة.
  4. اقترح حل واحد واقعي (One possible solution would be to…) واشرح مين هينفذه وإزاي.
  5. برّر الحل (This would help by… / This is effective because…): ليه هينفع؟ وليه واقعي؟
  6. اختم بـ Overall, … أو If this solution were adopted, … would…
  7. راجع: فقرة واحدة؟ مشكلة واحدة وحل واحد؟ كلمات من الدرس (emissions, landfill, convenience, informed…)؟ حوالي 150-180 كلمة؟

نموذج كامل (Model Answer)

Problem-Solution Paragraph: Half-Empty Delivery Vans176 words · يغطي نقاط الـ Writing Rubric الخمسة في الكتاب
Task: As a student writing for your school newsletter, write a problem-solution paragraph of about (150-180) words about one hidden cost of online shopping or delivery culture. Clearly state ONE specific problem and propose ONE realistic, specific solution.

A major problem with delivery culture is the large number of half-empty vans on our streets. Currently, many online shoppers choose free next-day delivery without a second thought. This happens because the option is quick and costs nothing at checkout. As a result, vans often drop just two or three parcels in each street and come back the next day for more, which produces too many emissions. One possible solution would be to offer a weekly "Green Delivery Day" when all of a customer's orders arrive together. Online stores could show this option first and give a small discount to customers who choose it. This would help by reducing the number of trips, since each van would carry consolidated orders instead of just a few items. This is effective because it does not ask anyone to stop shopping online. It simply makes the hidden cost visible and gives customers an informed choice. Overall, if this solution were adopted, our streets would be cleaner and the price on the screen would be closer to the real cost.

ليه النموذج ده قوي؟
  • Problem: أول جملة فيها المشكلة واحدة ومحددة: A major problem with delivery culture is the large number of half-empty vans (عبارة الكتاب + quantifier).
  • Currently, …: بتوصف الوضع دلوقتي (الناس بتختار next-day delivery من غير تفكير).
  • Explanation: السبب This happens because… والنتيجة As a result, … وليه مهمة: too many emissions (quantifier تاني + كلمة من الدرس).
  • Proposed Solution: حل واحد ومحدد وواقعي: One possible solution would be to offer a weekly "Green Delivery Day" + مين ينفذه وإزاي (Online stores could show this option first and give a small discount). الـ inverted commas حوالين الاسم لأنه مش اسم رسمي حقيقي.
  • Justification: This would help by reducing… (by + ing) + This is effective because…: الحل واقعي لأنه مش بيمنع الشراء أونلاين.
  • Vocabulary من الدرس: emissions, consolidated orders, hidden cost, informed choice, checkout.
  • Conclusion: Overall, if this solution were adopted, … would… = second conditional للنتيجة المتوقعة، وبترجع لفكرة الدرس (السعر على الشاشة مش هو التكلفة الحقيقية).
  • فقرة واحدة من غير عناوين، ومكتوبة لقرّاء مجلة المدرسة بأسلوب واضح ومحترم.

أشهر الأخطاء

غلط ← صح
  • ✗ تكتب 3 مشاكل (packaging + vans + returns) ← ✓ مشكلة واحدة محددة.
  • ✗ الحل: People should stop buying online forever. ← ✓ حل واقعي: Online stores could offer a weekly delivery day.
  • ✗ One possible solution would be offer… ← ✓ One possible solution would be to offer…
  • ✗ This would help by reduce trips. ← ✓ This would help by reducing trips.
  • ✗ If this solution was adopted, the streets will be cleaner. ← ✓ If this solution were adopted, the streets would be cleaner.
  • ✗ too many packaging / a large number of waste ← ✓ too much packaging / a large amount of waste.
  • ✗ تقترح الحل من غير ما تبرره ← ✓ لازم This is effective because…
  • ✗ تكتبها 4 فقرات بعناوين ← ✓ فقرة واحدة مركزة.

إزاي بييجي في الأسئلة؟

الأسئلة في الكتاب والمراجعات بتيجي بالشكل ده:

1) MCQ عن الـ genre (زي Consolidation Review E):

Which sentence belongs to the Justification part of a problem-solution paragraph? a) A major problem with online shopping is packaging waste. b) This is effective because it saves cardboard without stopping people from shopping online. c) Currently, many customers order several sizes of the same item. d) One possible solution would be to use smaller boxes.

الإجابة: b — This is effective because… بتشرح ليه الحل هينفع، وده الـ Justification. (a) و(c) مشكلة، و(d) الحل نفسه.

2) كمّل بالـ quantifier الصح:

A large … of water may be used to produce a single cotton T-shirt. a) amount b) number c) few d) many

الإجابة: a — water مبتتعدّش، فبنقول a large amount of.

3) JRE (زي أسئلة 10.1):

Do you think 'free' next-day delivery is really free? Give evidence for your answer.

J: No, I do not think 'free' next-day delivery is really free. R: The customer pays nothing at checkout, but the environment and workers pay a hidden cost. E: For example, the text explains that vans may deliver only a handful of items to one street and repeat the same half-empty route the next day, so the carbon cost becomes considerable. — لاحظ إن 'free' في inverted commas لأنها مش بمعناها الحرفي.

قائمة المراجعة (من الـ Writing Rubric في الكتاب)

  1. قلت المشكلة بوضوح؟ (مشكلة واحدة)
  2. شرحت ليه المشكلة مهمة؟ (سبب + نتيجة)
  3. اقترحت حل محدد وواقعي؟ (حل واحد)
  4. برّرت ليه الحل هينفع؟
  5. استخدمت كلمات دقيقة من الدرس؟
  6. زيادة: استخدمت quantifiers صح؟ فقرة واحدة؟ حوالي 150-180 كلمة؟

تدريب

أولًا: اختار الإجابة الصحيحة (a / b / c / d)

  1. 1. A problem-solution paragraph is … than a full essay. a) longer and less focused b) shorter and more focused c) more informal d) more imaginative

    Show answer
    b — الكتاب: shorter and more focused than a full proposal or essay.

  2. 2. One possible solution would be … clearer return policies. a) introduce b) introducing c) to introduce d) introduced

    Show answer
    c — would be to + المصدر.

  3. 3. This would help by … the amount of packaging. a) reduce b) reducing c) to reduce d) reduced

    Show answer
    b — بعد حرف الجر by بنستخدم ing.

  4. 4. If online stores … slower delivery options, emissions would fall. a) offer b) will offer c) offered d) offering

    Show answer
    c — second conditional: If + past ← would.

  5. 5. There are too … delivery vans in our street every morning. a) much b) many c) little d) amount

    Show answer
    b — vans بتتعدّ = many.

  6. 6. Online orders create a large … of cardboard waste. a) number b) many c) amount d) few

    Show answer
    c — waste مبتتعدّش = a large amount of.

  7. 7. Which sentence is the best Problem sentence? a) Shopping is fun. b) A major problem with online shopping is the huge number of returned clothes that are destroyed. c) I like my new shoes. d) Overall, it is good.

    Show answer
    b — مشكلة واحدة ومحددة بعبارة الكتاب.

ثانيًا: الجملة دي من أنهي جزء؟ (Problem / Explanation / Proposed Solution / Justification / Conclusion)

  1. 8. 'This happens because customers are not shown the environmental cost.'

    Show answer
    Explanation — بتشرح السبب.

  2. 9. 'A practical way to address this is to let customers choose smaller boxes.'

    Show answer
    Proposed Solution.

  3. 10. 'This is effective because it saves money for both stores and customers.'

    Show answer
    Justification — ليه الحل هينفع.

  4. 11. 'Overall, small changes at checkout could make a measurable difference.'

    Show answer
    Conclusion.

  5. 12. 'Currently, a large amount of packaging is thrown away after one use.'

    Show answer
    Problem — بتوصف المشكلة دلوقتي.

ثالثًا: True (T) أو False (F) مع التبرير

  1. 13. A good problem-solution paragraph discusses as many problems as possible.

    Show answer
    False — لازم ONE specific problem.

  2. 14. The solution must be realistic and specific.

    Show answer
    True — Propose ONE realistic, specific solution.

  3. 15. You do not need to explain why the problem matters.

    Show answer
    False — الـ rubric: I explain why it matters.

  4. 16. 'If this solution were adopted, …' is a suitable way to conclude.

    Show answer
    True — دي من عبارات الـ Conclusion في الكتاب.

رابعًا: صحّح الغلط

  1. 17. There is too many plastic in online deliveries.

    Show answer
    There is too much plastic… — plastic مبتتعدّش.

  2. 18. If customers knew the real cost, they will buy less.

    Show answer
    … they would buy less. — second conditional.

  3. 19. One possible solution would be ban free returns.

    Show answer
    One possible solution would be to limit free returns. (وكمان limit أوقع من ban لأنه أكثر واقعية.)

  4. 20. Few people knows what happens to returned items.

    Show answer
    Few people know — people جمع.

خامسًا: اكتب

  1. 21. Write a Problem sentence about oversized boxes.

    Show answer
    مثال: A major problem with online deliveries is that small items are often packed in boxes that are far too large.

  2. 22. Write a Justification sentence for this solution: 'Stores could offer reusable delivery bags.'

    Show answer
    مثال: This is effective because the same bag could be used many times, so a large amount of cardboard would be saved.

  3. 23. Write a Conclusion sentence using 'If this solution were adopted'.

    Show answer
    مثال: If this solution were adopted, fewer returned clothes would end up in landfill.
